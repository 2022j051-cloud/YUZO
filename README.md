# 遊蔵（ゆうぞう）

遊蔵は、ゲームコレクションをブラウザ内で管理するPWAです。タイトル、ハード、メーカー、エディション、品番、地域、シリーズ、ジャンル、タグ、発売日、クリア状況、メモなどを登録できます。マスターデータは初期状態では空で、利用者が自分のコレクションに合わせて登録します。

## 使い方

- ゲームの登録・編集、検索、絞り込み、並び替えに対応しています。
- ジャンル・タグ・ハード・メーカー・シリーズは、入力中の文字に応じて候補を表示します。候補にない名前も手入力できます。
- シリーズはマスタ辞書で親子関係を設定できます。表示は「子シリーズ < 親シリーズ」の順です。子シリーズ名と親シリーズ名はそれぞれ独立してクリックでき、絞り込みも親・子を別々に指定できます。
- 地域は `JA`、`US`、`EU` など、エディションとは別に登録できます。
- ゲーム情報と辞書のCSV入出力、完全バックアップ（`.yuzo`）の書き出しに対応しています。アプリ内に完全バックアップの復元機能あり。

## ジャケット画像

Wii・GameCubeは初期設定済みで、[Dolphinの公開タイトルデータ（英語・日本語）](https://github.com/dolphin-emu/dolphin/tree/master/Data/Sys)をオンライン照合し、GameTDB IDを特定して[GameTDBのカバー画像](https://www.gametdb.com/Wii/Downloads)を取得します。GameTDB IDは作品コード・地域コード・発行元コードで構成され、末尾2文字は発行元コードです（例：Nintendoの `01`）。そのため、品番末尾へ一律に `01` を付けるのではなく、タイトル・品番・地域をデータと照合します。その他のハードは、マスタ辞書で取得先のURLテンプレートを設定してください。「品番からジャケット取得」は、既存の画像がある場合も再取得を試せます。

URLテンプレートで使える変数：

- `${serial}`：品番
- `${title}`：タイトル
- `${platform}`：ハード名
- `${region}`：地域コード（例：`JA`、`US`、`EU`）

オンライン照合にはインターネット接続が必要です。公開タイトルデータを取得できない場合や候補が一意にならない場合は、タイトル・地域・品番を確認してください。その他のハードで品番が使えない場合は、`${title}` を使うテンプレート、画像ファイルのアップロード、画像URLの手入力を利用できます。「タイトル＋ハードで画像検索」ボタンも利用できます。

外部URLから画像を表示すると、指定した画像提供元への通信が発生します。画像の利用条件や権利については利用者自身で確認してください。

## データ保存とプライバシー

ゲーム情報や設定は、基本的に利用中のブラウザ内に保存されます。遊蔵本体はコレクション情報を公開先サーバーへ送信しません。ただし、外部URLのジャケット画像を使う場合は、その提供元へ通信が発生します。

- ブラウザのデータ消去や端末変更などでデータにアクセスできなくなる場合があります。完全バックアップ（`.yuzo`）を書き出して保管してください。アプリ内に復元機能があります。
- バックアップには個人のコレクション情報が含まれる場合があります。公開リポジトリにアップロードしないでください。

GitHub Pagesで公開されているHTTPSのURLを対応ブラウザで開いてください。


## v3: Wii品番形式とOCR
- Wiiの品番を実物の表記に合わせて `RVL-P-SMNJ(JPN)` 形式で保存します。
- 各エディションに「カメラ/OCR」ボタンを追加しました。スマートフォンではカメラ撮影、PCでは画像ファイル選択ができます。
- OCRはブラウザ内で実行しますが、初回利用時にTesseract.jsをCDNから読み込みます。そのため初回はインターネット接続が必要です。OCR結果は確認・修正してから品番に反映してください。
- OCR結果は自動保存されません。ゲーム登録画面で内容を確認し、「保存する」を押してください。
