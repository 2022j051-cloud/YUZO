# 遊蔵（ゆうぞう）

遊蔵は、ゲームコレクションをブラウザ内で管理するPWAです。タイトル、ハード、メーカー、エディション、品番、地域、シリーズ、ジャンル、タグ、発売日、クリア状況、メモなどを登録できます。マスターデータは初期状態では空で、利用者が自分のコレクションに合わせて登録します。

## 使い方

- ゲームの登録・編集、検索、絞り込み、並び替えに対応しています。
- ジャンル・タグ・ハード・メーカー・シリーズは、入力中の文字に応じて候補を表示します。候補にない名前も手入力できます。
- シリーズはマスタ辞書で親子関係を設定できます。表示は「子シリーズ < 親シリーズ」の順です。子シリーズ名と親シリーズ名はそれぞれ独立してクリックでき、絞り込みも親・子を別々に指定できます。
- 地域は `JA`、`US`、`EU` など、エディションとは別に登録できます。
- ゲーム情報と辞書のCSV入出力、完全バックアップ（`.yuzo`）の書き出しに対応しています。完全バックアップ（`.yuzo`）の復元機能もあります。復元すると現在のデータが置き換わるため、事前にバックアップしてください。

## ジャケット画像

WiiはDolphinが管理するGameTDB由来のタイトル一覧（日本語・英語）を初期設定し、6文字IDを照合してカバー画像を取得します。ゲームIDを品番から推測して生成するのではなく、タイトルデータに実在するID候補を照合します。GameCubeはWiiとは別のプロバイダーと `gc/cover` の画像URLを使い、初期状態ではlibretro-databaseのGameCube DATをタイトル索引に使用します。Wii用タイトル一覧は流用しません。タイトルデータは「6文字ID = タイトル」形式のテキストと、`name` / `serial` を含むDAT形式を解析できます。URL、タイトルデータ、カバーURLテンプレート、直近の候補・照合結果はゲーム登録画面の「取得元・直近の照合ログ」で確認できます。その他のハードは、マスタ辞書で独自URLテンプレートを設定してください。

URLテンプレートで使える変数：

- `${serial}`：品番
- `${title}`：タイトル
- `${platform}`：ハード名
- `${region}`：地域コード（保存した地域値。GameTDB組み込み処理では画像サービス用の地域値へ変換します）
- `${gameId}`：照合した6文字ゲームID
- `${extension}`：画像拡張子（`png` または `jpg`）

オンライン照合にはインターネット接続が必要です。公開タイトルデータを取得できない場合や候補が一意にならない場合は、タイトル・地域・品番を確認してください。その他のハードで品番が使えない場合は、`${title}` を使うテンプレート、画像ファイルのアップロード、画像URLの手入力を利用できます。「タイトル＋ハードで画像検索」ボタンも利用できます。

外部URLから画像を表示すると、指定した画像提供元への通信が発生します。画像の利用条件や権利については利用者自身で確認してください。

## データ保存とプライバシー

ゲーム情報や設定は、基本的に利用中のブラウザ内に保存されます。遊蔵本体はコレクション情報を公開先サーバーへ送信しません。ただし、外部URLのジャケット画像を使う場合は、その提供元へ通信が発生します。

- ブラウザのデータ消去や端末変更などでデータにアクセスできなくなる場合があります。完全バックアップ（`.yuzo`）を書き出して保管してください。復元時は現在のデータが置き換わります。
- バックアップには個人のコレクション情報が含まれる場合があります。公開リポジトリにアップロードしないでください。

GitHub Pagesで公開されているHTTPSのURLを対応ブラウザで開いてください。


## v3: Wii品番形式とOCR
- Wiiの品番を実物の表記に合わせて `RVL-P-SMNJ(JPN)` 形式で扱います。
- OCRでパッケージ品番を読み取れます。初回はTesseract.jsをCDNから読み込むためインターネット接続が必要です。

## v4: ライブOCR、ハード別取得設定、照合ログ
- カメラ映像を表示しながらOCRを繰り返し、検出した品番を映像上にタップ可能な候補として重ねて表示します。候補をタップすると品番と地域を登録欄へ反映します。画像ファイルから読み取る方法も残しています。
- 地域表記は `JPN` 固定ではありません。認識した3文字の地域表記を保持します。
- WiiとGameCubeを別プロバイダーに分離しました。WiiはDolphin管理のWiiタイトル一覧を使用します。GameCubeはWii用のタイトル一覧を流用せず、別のGameCube DATを初期設定しています。タイトルデータURLはハードの辞書設定で確認・変更できます。
- ハードの辞書設定でプロバイダー、タイトルデータURL（1行に1つ）、カバー画像URLテンプレートを確認・編集できます。テンプレート変数は `${serial}`、`${title}`、`${platform}`、`${region}`、`${gameId}`、`${extension}` です。
- ジャケット取得画面の「取得元・直近の照合ログ」で、設定URL、タイトルデータ件数、照合ID、画像URLの試行と結果を確認できます。
- GameCubeの品番 `GS(MLG)DOL-GBIJ-JPN` や `GS-DOL-GBIJ-JPN` などは括弧内コードの有無や表記の違いを保持し、検索用に4文字コードと地域を抽出します。括弧内コードをタイトルIDとみなしたり、発行元コードを推測したりしません。
