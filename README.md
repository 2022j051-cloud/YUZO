# 遊蔵（ゆうぞう）

遊蔵は、ゲームコレクションをブラウザ内で管理するPWAです。レトロゲームから現行機まで、タイトル・ハード・メーカー・品番・シリーズ・ジャンル・タグ・メモなどを登録できます。

## 使い方

- ゲームの登録・編集、検索、複数条件での絞り込み、発売日の範囲指定、並び替えができます。
- ハード別件数、表示項目、テーマ、ジャケット表示を設定できます。
- CSVの入出力と、ゲームデータ・画像・辞書・設定を含む完全バックアップ（`.yuzo`）の作成・復元に対応しています。

## ジャケット画像

ジャケット画像の取得先は初期設定されていません。必要な場合は、ユーザー自身で取得先を用意し、ハードのマスタ辞書を編集して「品番からジャケットを取得するURLテンプレート」を設定してください。設定先に画像が存在し、画像URLとしてアクセスできる必要があります。

URLテンプレートでは次の変数を使用できます。

- `${serial}`：品番
- `${code}`：品番（`${serial}`と同じ値）
- `${title}`：タイトル
- `${platform}`：ハード名

外部URLから画像を取得すると、画像取得先への通信が発生します。画像の利用条件や権利については、利用者自身で提供元を確認してください。

## データ保存とプライバシー

ゲーム情報や設定は、基本的に利用しているブラウザ内（IndexedDB。環境によってはlocalStorage）に保存されます。遊蔵は、ゲームコレクションのデータを公開先サーバーへ送信する仕組みを設けていません。

- ブラウザのデータ消去や別端末への変更などでデータにアクセスできなくなる場合があります。定期的に完全バックアップを保存してください。
- ジャケット画像を外部URLから取得する場合、その取得先へ通信が発生します。
- バックアップファイルには個人のコレクション情報が含まれることがあります。公開リポジトリにアップロードしないでください。

旧形式の`.rshelf`および`.json`バックアップも復元できます。

GitHub Pagesで公開されているHTTPSのURLを対応ブラウザで開いてください。ブラウザが対応している場合は、ブラウザのメニューからアプリとしてインストールできます。
