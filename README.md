# 遊蔵（ゆうぞう）

遊蔵は、ゲームコレクションをブラウザ内で管理するPWAです。タイトル、ハード、メーカー、エディション、品番、地域、シリーズ、ジャンル、タグ、発売日、クリア状況、メモなどを登録できます。マスターデータは初期状態では空で、利用者が自分のコレクションに合わせて登録します。

## 使い方

- ゲームの登録・編集、検索、絞り込み、並び替えに対応しています。
- ジャンル・タグ・ハード・メーカー・シリーズは、入力中の文字に応じて候補を表示します。候補にない名前も手入力できます。
- シリーズはマスタ辞書で親子関係を設定できます。表示は「子シリーズ > 親シリーズ」の順で、絞り込みも親シリーズ・子シリーズを別々に指定できます。
- 地域は `JA`、`US`、`EU` など、エディションとは別に登録できます。
- ゲーム情報と辞書のCSV入出力、完全バックアップ（`.yuzo`）の書き出しに対応しています。アプリ内に完全バックアップの復元機能はありません（後で追加します）。

## ジャケット画像

ジャケット画像の取得先は初期設定されていません。ユーザー自身で取得先を用意し、マスタ辞書の各ハードにURLテンプレートを設定してください。「品番からジャケット取得」を押すとテンプレートから画像を読み込みます。

URLテンプレートで使える変数：

- `${serial}`：品番
- `${title}`：タイトル
- `${platform}`：ハード名
- `${region}`：地域コード（例：`JA`、`US`、`EU`）
- `${region}` を推奨

品番がデータベースに存在しないハード（例：一部の古いカートリッジ機）では、利用する画像サイトがタイトルをURLに使える場合、`${title}` を使ったテンプレートを設定できます。画像サイト側のURL形式がタイトルに対応していない場合は、画像ファイルを直接アップロードするか、画像URLを手入力してください。「タイトル＋ハードで画像検索」ボタンから、タイトルとハード名を使った画像検索を手動で開くこともできます。

外部URLから画像を表示すると、指定した画像提供元への通信が発生します。画像の利用条件や権利については利用者自身で確認してください。

## データ保存とプライバシー

ゲーム情報や設定は、基本的に利用中のブラウザ内に保存されます。遊蔵本体はコレクション情報を公開先サーバーへ送信しません。ただし、外部URLのジャケット画像を使う場合は、その提供元へ通信が発生します。

- ブラウザのデータ消去や端末変更などでデータにアクセスできなくなる場合があります。完全バックアップ（`.yuzo`）を書き出して保管してください。アプリ内に復元機能はありません（後で追加します）。
- バックアップには個人のコレクション情報が含まれる場合があります。公開リポジトリにアップロードしないでください。
